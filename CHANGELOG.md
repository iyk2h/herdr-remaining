# Changelog

## 1.1.1

This version corrects these problems:

- CLI modes return JSON through directory aliases and paths with spaces.
- The preview includes its own icons and rings before the widget installation.
- Invalid native case names fail before file changes or native checks.
- Developer tests cover both helpers without app access.

## 1.1.0

This version adds these features:

- Release packages include checksums and native validation.
- Updates preserve user files and refuse changed managed code.
- Rollback and recovery protect settings during interrupted updates.
- Model recommendations require explicit reported IDs or names.
- The repository includes a recipe and a preview with example accounts.

## 1.0.0 — development baseline

The baseline includes these features:

- Bars and Rings show reported limits with reset countdowns.
- Account discovery reuses CLI logins with identity checks.
- JSON themes use a bounded schema.
- Diagnostics omit private account data.
- Account recommendations support saved data or an explicit refresh.
- Settings support versioned backup and restore.
